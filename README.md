# GLTC联合协议
GLTC联合协议是一款利用RykenSlimeCustomizer制作的独立且原创的Slimefun4附属，其提供的所有物品与机器中的名称与描述皆非AI生成。  
本附属是提供了大量物品、道具、武器装备与机器的粘液科技附属，采用不同的势力划分时期、功能，在体量较大的同时保持了可玩性与物品用途与来源的清晰性。  
本附属添加了大量独特而有趣的机制与系统，例如异能武器、魔素与订单机制。  
从构造蓝图开始，逐步重现大崩溃后失落已久的技术与奇迹，逐步发展出涵盖金属、生物、锻造、魔素等技术构成的复合工业体系；  
且能源流系统能消耗多余的基础物品，自由且便捷的兑换大量原版材料，优化空岛或家里蹲玩家的游戏体验。（持续更新中）  
*关于设定背景中的“人之领”与“大崩溃”：来自于游戏“远行星号”。  
*关于所有道具/机器的脚本：功能实现来源于AI。  
*关于粘液科技：GLTC联合协议与粘液科技的体系完全切割，在不游玩原版粘液科技的情况下仍然能正常游玩。  
  
  
  
第一阶段：  
ATO协会与星渊造物：提供基础材料，构造蓝图。  
白铃山矿业 / 霆石重工 (C/TS)：对应怒晖座，第一阶段主要势力，专注矿物开采、合金精炼与悖论能源处理，是整个第一阶段工业体系的基础与骨架。  
莉尔幸丝有机声学工业 (LSIA)：对应四想座，以声音旋律与创世碎片为核心，通过录制生物和弦、谱写乐章，产出高级材料与所有原版材料。  
伊赭璃离岸工业群专利管理工会 (EAE)：对应风眼座，以辅助与便利性机器为主，作为流程与生产线优化性势力出现。  
缪尔罗素烘炉精密工坊 (FKRT)：对应炼诏拳座，能够生产常规或带有特殊效果的武器、工具和护具，还能制造一些独特的异能武器与枪械。  
魔药联合™食药工程有限公司 (UMPV)：对应涟音座，能够生产大量各式农作物、畜牧产物与药物，能够制造强大的料理与药物，以及发电机器。  

第二阶段：  
Sekthiy远征星航舰（Skey）:对应风海深渊滞留域，以能源土为核心生产大量与核能有关的材料与高级合金，作为第一到第二的承上启下势力出现。  
环夜谷巅峰术士学会（VASA）：对应噬空座。  

DLC：  
奥史莱特中古科技爱好者协会 (OST)：对应由蕨座，通过将基础物品转换为逻素，快速生产原版粘液科技的物品的势力，作为优化粘液流程出现的势力。  
乎维米亚运输网络供应商（HInet）：对应琴廊座，通过一些简单的机器，将基础物品转化为网络附属于应用能源附属的材料与管道，作为优化货运系统而出现的势力。
