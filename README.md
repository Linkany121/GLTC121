# GLTC121
GLTC联合协议是一款利用RykenSlimeCustomizer制作的独立且原创的Slimefun4附属，其提供的所有物品与机器中的名称与描述皆非AI生成。

*关于设定背景中的“人之领”与“大崩溃”：来自于游戏“远行星号”。

*关于所有道具/机器的脚本：功能实现来源于AI。

*关于粘液科技：GLTC联合协议与粘液科技的体系完全切割，在不游玩原版粘液科技的情况下仍然能正常游玩。

GLTC联合协议是一款提供了大量物品、道具、武器装备与机器的粘液科技附属，采用不同的势力划分时期、功能，在体量较大的同时保持了可玩性与物品用途与来源的清晰性。
从构造蓝图开始，逐步重现大崩溃后失落已久的技术与奇迹，逐步发展出涵盖金属、生物、锻造、魔素等技术构成的复合工业体系，
例如：
ATO协会与星渊造物：提供基础材料，构造蓝图。
白铃山矿业 / 霆石重工 (C/TS)：对应怒晖座，第一阶段主要势力，专注矿物开采、合金精炼与悖论能源处理，是整个第一阶段工业体系的基础与骨架。
莉尔幸丝有机声学工业 (LSIA)：对应四想座，以声音旋律与创世碎片为核心，通过录制生物和弦、谱写乐章，产出高级材料与所有原版材料。
